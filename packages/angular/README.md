# @fewcompany/angular (reservado)

Adaptador Angular do design system. Ainda sem código.

Quando for iniciado:
- Consome `@fewcompany/core` (tokens, `styles.css`, funções headless). Não duplica lógica nem CSS.
- Um componente/diretiva por parte composta, com content projection (`ng-content`) no lugar de `asChild`.
- Mesmos nomes de partes e atributos `data-state` do adaptador React, para o CSS `few-*` servir igual.
